# BatProjects
Projects I made for fun related to batman (or superheroes in general)

**BatBoysPolymorphism:**

simple Java demo focusing on polymorphism. This is a lightweight example showing how Java can treat different Bat Boys as the same “character” type while still invoking their unique actions.

**CharacterBatBoys:**

This file defines a small Java inheritance example for a “BatBoys” character system. This file is demonstrating polymorphism and inheritance: each character shares the same base class and behavior method name, but performs different actions in each subclass.

**Batgirls_Identities and Batgirls_Polymorphism:**

BatGirls_Identities defines an abstract base class named while BatGirls_Polymorphism creates instances of all three subclasses. This program demonstrates how one method call can produce different outputs depending on the actual object type.
